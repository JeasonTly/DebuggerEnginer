## 0. 阅读须知

### 0.1 冲突裁决（先看）

原型是 HTML 近似稿，WPF 落地时有几处与 DESIGN.md 不一致。按下表裁决，不要自行取舍。

| # | 项 | 原型值 | DESIGN / 计划 | 裁决 |
|---|---|---|---|---|
| C1 | 页面标题字号 | `h1` 18px | `page-title` 22 / 600 / 行高 1.25 | **取 DESIGN：22**。原型是浏览器缩放近似稿 |
| C2 | 正文字号 | body 13px | `body` 14 / 行高 1.4 | **取 DESIGN：14**；表内/辅助 12，极次要 11 |
| C3 | 系统应用的授权/卸载 | 渲染但 `disabled` | DESIGN：「系统项无授权/卸载」「不要给系统应用提供一键授权入口」；计划：「禁用」 | **不渲染这两个按钮**（不是灰显）；用固定宽度的操作区保证行内对齐不跳。启动、清数据照常 |
| C4 | 折叠态导航项 | CSS `justify-content:center` | DESIGN：图标**左对齐**，禁止水平居中 | **取 DESIGN**。展开/折叠两态图标 X 坐标必须相同（距导航项左缘 10px），见 §1.3 |
| C5 | 导航图标 | 两字母占位 `DI/AP/…`，折叠按钮用 `☰`/`»` 字符 | 不得用 Emoji；统一 Fluent/矢量图标 | **全部换矢量图标**，包括折叠按钮 |
| C6 | 控制台 logcat 关键字 | 生成 `logcat … \| findstr /i` | 计划 §7：应用内过滤，控制台不支持 `\| findstr` 管道 | **应用内过滤**；填入栏的文本不得含管道（见 §7） |
| C7 | 控制台固定高度 | `height:480px` | 页面应随窗口伸缩 | 控制台输出区**填满剩余高度**，不写死 480 |
| C8 | 窗口控制 | 三个灰圆点占位 | WPF 标准窗控 | 使用系统最小化/最大化/关闭，不画圆点 |
| C9 | 状态栏「最小 1100×700」 | 原型里展示的说明文字 | 仅为说明 | **不放进正式状态栏**；改为实际窗口最小尺寸约束 |
| C10 | 原型 `SCRCPY` 角标、`LIVE` 标签、手机壳 | 示意 | 真实投屏 | 正式版画面区显示真实 scrcpy 画面；`LIVE` 仅在会话运行中显示 |

> 若产品方要推翻某条裁决，需先改 DESIGN.md，再改本表。

### 0.3 全局状态约定

| 状态 | 约定 |
|---|---|
| 无当前设备 / 设备离线 | 页内显示「设备已断开」空态，保留缓存；操作按钮禁用并 tooltip 说明；设备芯片显示灰点 + 「离线」文案 |
| 加载中 | 列表区显示骨架或不确定进度条；已有缓存先显示，再增量刷新；不得整页白屏 |
| 读取失败 | 字段显示「—」并在其下/ tooltip 说明原因；整页失败显示原因 + 「重试」；不留空白 |
| 长任务 | 必须给进度，且明确「可取消」或「不可取消」；状态栏显示进行中任务 |
| 高危操作 | 系统 Monkey、`setenforce 0`、删除、根目录写操作 → 二次确认模态，命令写入日志 |
| 禁用控件 | 透明度 .45 + `not-allowed`；**必须有 tooltip 说明原因**（如「目录只读」） |
| 状态不能只靠颜色 | 在线/离线用 点+文案；权限用 文字标签+色；选中用 复选框+底色 |

- [ ] 宽：展开 **168**，折叠 **56**；右边框 1px Border；底 SurfaceBackground；内边距 8；项间距 2；`overflow:hidden`
- [ ] **折叠/展开按钮**：导航**顶部**唯一一枚（**不要**再做底部折叠条）；高 32、满宽、圆角 6、无底；图标 TextSecondary，悬停底 SurfaceRaised + 文字 TextPrimary；与下方项间距 4

## 2. 设备信息（Device Info）

### 2.1 布局

- [ ] 页头：标题「设备信息」；副标题「电量 · 存储 · 分辨率 · 内核/基带 · 安全补丁 · 网络类型（Wi‑Fi 含 MAC）· 运行时间」；右侧 `[复制摘要 Secondary][刷新 Primary]`
- [ ] 页体自上而下：
  1. **三列指标卡行**（`g3`，列间距 10~12，下间距 12）：电量 / 内部存储 / 系统运行时间
  2. **两列信息卡行**（`g2`，间距 12）：「构建 / 安全」、「显示 / 内核 / 网络」
  3. **两列行**（`g2`，上间距 12）：「内存」指标卡、「摘要」文本卡
- [ ] 卡片 `panel`：SurfaceBackground，1px Border，圆角 6，内边距 12；卡标题 12/600 TextSecondary，下间距 8

### 2.2 指标卡

- [ ] 结构：标签（11 TextSecondary）→ 大数值（**22/600，等宽数字 tabular-nums**，上间距 4）→ 副文（11 TextSecondary）→ 进度条
- [ ] 进度条：高 6，全圆角，底 SurfaceRaised，填充 Accent，上间距 8
- [ ] **电量**：数值 `76%`，副文「在线/离线」或充电状态；进度条宽 = 电量%
- [ ] **内部存储**：数值 = 已用，副文 `62 / 128 GB`；进度条 = 已用占比（真实计算，不得写死原型的 48%）
- [ ] **内存**：数值 = 已用，副文 `5.8 / 8 G`；进度条真实占比（不得写死 70%）
- [ ] **系统运行时间**：数值字号 20；格式 `HH:MM:SS`，≥1 天为 `N天 HH:MM:SS`；副文「已运行 N 秒 · 实时刷新」；**每秒刷新**；进度条为装饰性（不透明度 .35）
  - 实现：定期读取 `/proc/uptime` 校准，本地每秒递增；切换设备/离线时停止并重置
- [ ] 阈值色（可选，须配文字）：电量 <20%、存储/内存 >90% 时进度条用 Warning/Danger，并在副文给出文字提示

### 2.3 信息卡（`kv` 两列网格）

- 网格：`100px 1fr`，行距 6，列距 10；`dt` 12px TextSecondary，`dd` **等宽 11.5px**

**「构建 / 安全」**必含：
- [ ] 型号
- [ ] Android 版本
- [ ] Build 类型（user / userdebug / eng）
- [ ] **安全补丁**
- [ ] Serial

**「显示 / 内核 / 网络」**必含：
- [ ] **分辨率 · 密度**（如 `1080 × 2400 · 420 dpi`）
- [ ] **内核版本**
- [ ] **基带版本**
- [ ] **网络类型**（Wi‑Fi / 移动数据 / 以太网 / 无）
- [ ] 仅当网络类型 = Wi‑Fi：**Wi‑Fi SSID** 与 **Wi‑Fi MAC**（非 Wi‑Fi 时这两行**不显示**）
- [ ] IP
- [ ] OEM
- [ ] ADB 通道（USB / Wi‑Fi / 模拟器）
- [ ] ABI
- [ ] MAC 旁加说明提示：「Android 10+ 默认随机 MAC，此为当前连接所用地址」（tooltip 或次行 11px）

**「摘要」**：一段 12px 文字，形如 `型号 · 网络类型 · MAC xx · 补丁 yyyy-mm-dd`；「复制摘要」复制同样内容的完整文本。
